# Pets Feliz - Petshop

Projeto acadêmico de desenvolvimento de um sistema web para um petshop.

## Objetivo

O projeto Pets Feliz - Petshop tem como objetivo desenvolver um sistema web para apresentar produtos e serviços de um petshop, permitindo também o cadastro de clientes e pets e o agendamento de serviços.

## Funcionalidades

O sistema possui:

- Página inicial com informações sobre o petshop
- Carrossel de imagens utilizando Bootstrap
- Exibição dinâmica da data e hora atual utilizando JavaScript
- Três categorias de produtos:
  - Alimentação
  - Brinquedos
  - Higiene e Cuidados
- Seis produtos com imagem, descrição e valor
- Serviços de Banho e Tosa
- Cadastro de clientes
- Cadastro de pets
- Escolha entre os serviços de Banho e Tosa
- Escolha entre Tele-busca ou entrega do pet no local
- Seleção de data e horário para o agendamento
- Confirmação do agendamento utilizando JavaScript
- Página de ajuda para orientação do usuário
- Recursos de acessibilidade por meio de textos alternativos nas imagens.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- GitHub
- GitHub Pages

## Estrutura do projeto

- `index.html` - Página inicial
- `produtos.html` - Página de produtos
- `servicos.html` - Página de serviços
- `cadastro.html` - Cadastro do cliente, pet e agendamento
- `ajuda.html` - Página de ajuda
- `css/style.css` - Arquivo de estilos
- `js/script.js` - Funções JavaScript
- `imagens/` - Imagens utilizadas no projeto

## Ajustes realizados na Fase 2

Na Fase 2, o sistema desenvolvido anteriormente foi aprimorado com recursos visuais e novas funcionalidades.

Foi adicionada estilização utilizando CSS e Bootstrap, tornando as páginas mais organizadas e responsivas. Na página inicial foi implementado um carrossel de imagens utilizando Bootstrap.

Também foi adicionado JavaScript para tornar o sistema mais dinâmico. Foi implementada uma função temporal para apresentar e atualizar a data e a hora atual, além de uma função para apresentar uma mensagem de confirmação após o preenchimento do formulário de agendamento.

Foi criado um formulário para cadastro do cliente contendo nome, endereço, CPF, sexo, telefone e e-mail. Também foram adicionados campos para cadastro do pet, contendo nome, raça, idade e tipo de pet.

O formulário utiliza diferentes elementos e atributos HTML, como campos de texto, e-mail, número, radio buttons, checkbox, placeholder e campos obrigatórios.

Foram mantidos os dois serviços solicitados, Banho e Tosa. No agendamento, o usuário pode escolher entre Tele-busca ou entrega do pet no local e selecionar a data e o horário desejados.

Como recurso de acessibilidade para pessoas com deficiência visual, foram utilizados textos alternativos por meio do atributo `alt` nas imagens do sistema.

Também foram realizados testes e correções nos caminhos dos arquivos CSS e JavaScript para garantir o correto funcionamento do sistema no GitHub Pages.
